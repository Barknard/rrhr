# Music

Drop the music files here, named like this:

| File | Plays on |
|---|---|
| `menu.mp3` | The intro screens: the 18+ gate, the title and every menu (it keeps playing between them) |
| `race_slag_pit_speedway.mp3` | Races on Slag Pit Speedway |
| `race_cinder_switchback.mp3` | Races on Cinder Switchback |
| `race_magma_mile.mp3` | Races on Magma Mile |
| `race_king_cinders_crucible.mp3` | The boss race, King Cinder's Crucible |

- MP3s, looped seamlessly if you can. Keep each under about 5 MB so the website stays quick.
- A track you don't have yet just plays silence; one file used for every race is fine too (copy it under each name).
- Files here are committed and published with the game, so only use music you have the rights to.
